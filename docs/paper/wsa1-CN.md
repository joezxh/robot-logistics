# WSA₁：以 3D 为中心的世界-空间-动作通用机器人控制模型

## 摘要

具身 AI 的最新进展已将机器人基础模型（RFM）确立为通用机器人系统的主流方法。通过在大量机器人演示上进行模仿学习，RFM 在将视觉观测和语言指令映射到连续机器人动作方面取得了令人印象深刻的能力。然而，当前 RFM 缺乏对物理动力学和机器人行为对 3D 物理世界因果效应的内在推理能力。这在以 2D 为中心的视觉感知和以 3D 为中心的具身交互之间造成了根本性不匹配，严重限制了 RFM 在真实世界场景中的泛化能力。为弥合这一差距，我们提出 WSA₁——一种基于所提出的以 3D 为中心的世界-空间-动作建模范式的新型 RFM。它不仅学习面向未来机器人行为的 3D 世界感知视觉思维，还建模 3D 世界状态转换与机器人动作之间的相互约束以增强行为泛化。值得注意的是，WSA₁ 以 6000 小时的专家演示数据（仅 1000 小时来自真实机器人）实现了高效预训练，同时在 RoboTwin2.0 仿真基准上实现了竞争性操作性能（93% 成功率），并在真实世界机器人控制任务上比最先进的 RFM 平均提升 +20%。这些结果表明，当配合以 3D 为中心的世界-动作联合建模时，可泛化的 RFM 无需大规模真实机器人数据即可实现，为通用机器人系统提供了实用且经济的路径。
