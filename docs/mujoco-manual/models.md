# Model Gallery

## MuJoCo Menagerie

A physics simulator is only as good as the model it is simulating, and in a powerful simulator like MuJoCo with many modeling options, it is easy to create “bad” models which do not behave as expected. The goal of **MuJoCo Menagerie** is to provide the community with a curated collection of well-designed models that work well right out of the box.

For more information, visit the [Menagerie repository](https://github.com/google-deepmind/mujoco_menagerie).
