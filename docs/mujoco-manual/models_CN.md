# 模型画廊

## MuJoCo Menagerie

一个物理仿真器的好坏，取决于它所仿真的模型；而在像 MuJoCo 这样拥有众多建模选项的强大仿真器中，很容易创建出“糟糕”的模型——它们并不会按预期的方式表现。**MuJoCo Menagerie** 的目标是向社区提供一组精心挑选、开箱即用的优质模型集合。

更多信息，请访问 [Menagerie 仓库](https://github.com/google-deepmind/mujoco_menagerie)。
