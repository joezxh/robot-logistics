### 1.4 首评结论（决策参考）

1. **箱装（2.2.2）/ 袋装（2.2.1）/ 桶装（2.2.3）/ 托盘单元（2.2.7）**是四大**主流场景**，A/B/C/D/E 五类方案均可贡献价值；推荐组合优先级：**D 复合 ≈ C 插齿 > B 夹爪 > A 负压**（按货物尺寸越大、形态越规则越偏向 C/D）。
2. **异形件（2.2.8）**与**异形箱（2.1.4）**强烈依赖 **D 复合 + 强感知 + 强规划**，A 类几乎不可行。
3. **颗粒散货（2.2.5）**与**冷藏集装箱（2.1.3）**有较高工程难度，需在 A/B/C 上做专项改造。
4. **破损 / 渗漏（2.1.7）**优先考虑 D + E 协同（隔离区 / 收集槽 / 二次处置）。
5. **装箱（反向 2.1.5）**与**偏载（2.1.6）**强依赖 WMS/任务调度（E 类）+ 强规划 + 在线重心估计。

### 2.1 集装箱场景

#### 2.1.1 标准 20/40ft 集装箱掏箱 → 传送带

**定义**
标准干货集装箱（20ft / 40ft，内宽约 2.33m，内高约 2.69m），内装规则箱件、袋装或桶装的混合货，作业终点为下游传送带。节拍目标 6~10 件/min（按货物大小与重量）。

**难点**
1. **空间狭窄**：箱内可操作空间约 2.3m 宽 × 2.6m 高，机械臂 + 末端长度必须 < 2.4m 以避免与箱壁干涉。
2. **混合 SKU**：箱内可能有瓦楞箱、编织袋、塑料桶混装，单一抓取策略不可行。
3. **节拍高**：传送带节拍与机器人节拍需同步，等待时间会拖垮整体 OEE。
4. **门位环境**：集装箱门关闭后作业，照度不足、温差大、Wi-Fi/5G 信号弱。
5. **末端行程长**：从箱门口到最远端约 12m（40ft），需考虑臂展与节拍折中。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | 🟡 3 | 顶部平整瓦楞箱（≤25kg） | 顶部不平整/袋装不适用；侧面抽吸需要随形罩 |
| B 夹爪 | ✅ 4 | 几乎所有规则件 / 桶 / 厚袋 | 单次只能抓取 1 件 |
| C 插齿托举 | ✅ 4 | 托盘单元、底部有托盘/底板的箱件 | 桶装、袋装、零散件不适用 |
| D 复合 | ✅ 4 | 任意（夹爪+吸盘+叉型融合） | 成本高；维护复杂 |
| E 链路 | ✅ 4 | — | 需视觉定位 + 传送带对齐 + 调度同步 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合式** 为主（双臂 / 双末端快换 + 视觉伺服）；具体末端为 **B 夹爪（主）+ A 吸盘（次，针对顶部平整箱）+ C 托举（次，针对有底板箱）** 的快换三件套。
- **链路 E**：
  - 传送带同步控制（节拍自适应）：当传送带下游堵塞时机器人进入 **微停顿 + 摆动减速** 模式，避免空中积压。
  - 视觉系统：箱内 3D 重建（结构光 + ToF 融合），门位相机（门开启自动校准）。
  - WMS 接口：按 SKU 推送 目标位姿 + 重量 + 优先级，机器人按优先级抓取。
  - AGV 入仓衔接（可选 2.1.2 升级）：末端放下后由 AGV 接力。
- **冗余路径**：
  - 主臂故障 → 切换备用臂（双冗余）。
  - 视觉失效 → 力控抓取（基于重量的盲抓，需提前在 WMS 中标记盲抓 SKU）。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| 箱内货物倒塌 | 中 | 双臂协调托举；切换至 B 夹爪 + 兜底平台 |
| 末端撞箱壁 | 高 | 强化虚拟围栏；LiDAR 安全 + 力控阻抗 |
| 视觉失效（光照/粉尘） | 中 | 切力控盲抓；切 IR 结构光补光 |
| 传送带下游堵塞 | 中 | 节拍自适应 + 末端摆动暂存模式 |
| 节拍不达标 | 中 | 引入双臂并行（双末端接力） |

**备选**

- 全 **B 夹爪**（最便宜但节拍较低）+ E 节拍自适应；适合低节拍要求。
- 全 **C 叉型**（仅适用托盘/底板单元）+ E 视觉对位。

**关键指标（KPI）**
- 单件节拍：≤ 6s（瓦楞箱 ≤ 15kg），≤ 9s（袋装 ≤ 30kg）
- 抓取成功率：≥ 99.5%
- 箱壁碰撞：0 次/千件
- 传送带同步误差：≤ ±200ms

#### 2.1.2 标准集装箱掏箱 → AGV 入仓

**定义**
同 2.1.1，但末端不直接放入传送带，而是放在 **AGV** 上由 AGV 接力送入仓内货架/暂存区。节拍目标略低（4~8 件/min），但末端精度更高（与 AGV 对位误差 < 5mm）。

**难点**
1. **末端交接精度**：AGV 在 ±10mm 范围内停车，机器人需在 ±5mm 内放置。
2. **多 AGV 调度冲突**：多 AGV 并发时，机器人放置位置不能与其他 AGV 当前任务位冲突。
3. **AGV 通信延迟**：5G/Wi-Fi 时延波动 10~50ms，需做预测补偿。
4. **末端夹持时间**：AGV 到达前机器人需悬停等待，最坏情况 1~3s，影响节拍。
5. **AGV 异常撤离**：AGV 故障时机器人需快速识别并切换目标 AGV 或临时放置区。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | 🟡 3 | 同 2.1.1 | AGV 顶部放置受限 |
| B 夹爪 | ✅ 4 | 同 2.1.1 | 精度满足 AGV |
| C 插齿托举 | ✅ 4 | 托盘/底板单元 | AGV 顶部放置受限 |
| D 复合 | ✅ 4 | 同 2.1.1 | 同 2.1.1 |
| E 链路 | ✅ 4 | — | AGV 调度 + WMS + 队列管理为核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合 + B 夹爪为主**，配合 **C 托举**（针对有底板件）。
- **链路 E**：
  - **AGV 调度系统**（详见第 4 章 E-2）：任务队列、避让、动态路径。
  - **放置位预测**：基于 AGV 实时位姿（毫米波定位 + 视觉地标），提前 1~2s 预测停车点。
  - **多 AGV 冲突解决**：调度器在机器人放置前 0.5s 锁定目标 AGV，避免冲突。
  - **WMS 接口**：推送 SKU + 目的库位 → AGV 调度器 → 机器人执行。
  - **异常接管**：AGV 故障时自动重派最近可用 AGV；若无可用则放入临时缓冲区。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| AGV 通信延迟 | 中 | 预测补偿 + 滞后校验 |
| AGV 故障 | 高 | 自动重派 + 临时缓冲区 |
| 末端对位超差 | 中 | 视觉二次校准 + 力控贴合 |
| AGV 满载/调度冲突 | 中 | 优先级重排 + 等待队列 |
| 抓取等待时间过长 | 中 | 引入中间缓存区（短传送带） |

**备选**

- **D 复合 + E + 双 AGV 队列**：双 AGV 并行接力（机器人只管放，AGV 调度决定谁先到）。
- **B 夹爪 + 短传送带 + E**：用短传送带作为缓存（机器人→短带→AGV）。

**关键指标（KPI）**
- 末端放置精度：±5mm
- AGV 对接时延：≤ 1.5s（含 AGV 到位等待）
- AGV 调度冲突率：≤ 1%
- 抓取节拍：≤ 8s/件（含 AGV 接力）

#### 2.1.3 冷藏集装箱（恒温带冷凝）

**定义**
冷藏集装箱（Reefer，内温 -30°C ~ +30°C 可调），掏箱作业时箱门开启后会快速结露，箱壁/货物表面出现冷凝水，温度可能持续 -25°C ~ +10°C。

**难点**
1. **低温环境影响**：液压油黏度变化、润滑脂凝固、电子元件低温漂移、机械间隙收缩。
2. **冷凝水打滑**：吸盘失效（负压不足，密封圈湿滑）、夹爪打滑、纸箱表面吸水软化。
3. **货物表面冰霜**：袋装、瓦楞箱表面可能结冰霜，摩擦系数大幅下降。
4. **作业窗口短**：开门后温升快（20min 内可能升至 +5°C），冷链要求 30min 内完成作业。
5. **冷凝水收集**：不能污染集装箱地板与下游传送带。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | 🟡 2 | 需带随形罩 + 防滑密封圈；仅平整干态表面可用 | 冷凝水打滑风险高 |
| B 夹爪 | 🟢 3 | 自适应夹爪（带防滑纹 + 力控） | 软冰冻袋装不适用 |
| C 插齿托举 | 🟢 3 | 托盘/底板单元 | 需防冰冻卡阻 |
| D 复合 | 🟢 3 | 同上 | 需耐低温电池/润滑 |
| E 链路 | 🟢 3 | — | 需冷凝水收集槽 + 临时温控棚 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合 + C 托举为主**（托举避开了表面摩擦问题），配 **B 夹爪（带防滑纹 + 加热元件）**。
- **耐低温改造**：
  - 关节润滑脂更换为低温脂（-40°C 适用）。
  - 末端执行器加热带（防结冰，启动时预热 5min）。
  - 电池低温版（带自加热膜）。
- **链路 E**：
  - **冷凝水收集槽**：集装箱门下方铺设 V 形槽，接入排水。
  - **临时温控棚**：门位装可伸缩气帘，减少开门温升速率。
  - **作业节拍管理**：WMS 优先排出冷柜，缩短开门时间。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| 末端结冰卡阻 | 高 | 加热带 + 启动预热 + 防冰润滑 |
| 冷凝水导致抓滑 | 高 | 切换 D+C 托举（避开表面） |
| 电池低温衰减 | 中 | 自加热电池 + 备机轮换 |
| 冷链超温 | 中 | WMS 节拍优先 + 多人/多机协作 |
| 冷凝水污染下游 | 中 | 收集槽 + 防滴落末端 |

**备选**

- **D 复合（防冰改造）**：吸盘/夹爪均带加热带与防滑纹。
- **C 插齿托举专用机**：仅适用托盘单元，最稳。

**关键指标（KPI）**
- 冷柜作业时间：≤ 30min（含开门到关门）
- 末端冷启动成功率：≥ 95%（预热后）
- 冷凝水收集率：100%

#### 2.1.5 装箱（反向：散件 → 集装箱）

**定义**
反向作业：散件通过传送带/AGV 进入集装箱，机器人按装载率最大化原则码放。可类比 3D 装箱问题（CVRP/3D-BPP）。

**难点**
1. **装载率最大化**：3D 装箱是 NP-hard，需实时求解（在线 3D-BPP 算法）。
2. **防塌垛**：上层重下层轻时整体稳定性差，需动态重心估计。
3. **节拍与算法折中**：算法求解时间需 ≤ 0.5s/件。
4. **码放模式**：箱件平铺/竖放/翻转，需根据尺寸实时决策。
5. **箱内空间利用率报告**：实时输出装载率给 WMS。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | 🟡 2 | 顶部吸附放置（仅部分场景） | 侧面吸附放置不适用 |
| B 夹爪 | 🟢 3 | 通用 | 需支持多自由度放置姿态 |
| C 插齿托举 | 🟢 3 | 托盘/底板单元 | 零散件不适用 |
| D 复合 | ✅ 4 | 任意 | 必备 |
| E 链路 | ✅ 4 | — | 3D-BPP 在线算法 + WMS 反馈为核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合 + B 夹爪（多自由度）**。
- **链路 E**：
  - **3D-BPP 在线求解器**：基于深度学习 + 启发式（NF/EF/Blossom），单次决策 ≤ 200ms。
  - **实时重心估计**：在线 SLAM + 视觉重建箱内堆叠。
  - **WMS 双向接口**：WMS 推送 SKU 序列 → 3D-BPP 输出码放顺序 → 机器人执行 → 反馈装载率。
  - **AGV 入位协同**：AGV 跟随到箱门口，机器人从 AGV 直接取件（减少落地次数）。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| 3D-BPP 求解超时 | 中 | 启发式快速回退（贪心 + 旋转） |
| 装载率不达标 | 中 | WMS 重排 SKU 顺序 |
| 堆叠塌垛 | 高 | 力控轻放 + 实时重心校验 + 触发重排 |
| 节拍不达标 | 中 | 多末端并行 + 缓存区 |

**备选**

- **C 托举 + 整托入箱**：仅适用同 SKU 同尺寸。
- **人工 + 3D-BPP 提示**：半自动模式。

**关键指标（KPI）**
- 装载率：≥ 85%（混合 SKU）/ ≥ 95%（同 SKU）
- 3D-BPP 求解时延：≤ 200ms/件
- 塌垛率：≤ 0.1%
- 单件码放节拍：≤ 6s

#### 2.1.6 偏载 / 重心偏移 / 顶层悬挑

**定义**
集装箱内货物堆叠不规则，存在明显重心偏移、顶层悬挑（货物部分悬空于下层支撑之外）。机器人需在不规则堆叠下安全抓取。

**难点**
1. **重心不可见**：仅靠外视觉难以估计重心，需多视角融合 + 力探测。
2. **悬挑抓取**：抓取瞬间下层支撑可能倒塌（连锁反应）。
3. **重心偏移**：抓取后整机侧翻风险高。
4. **不能破坏下层**：抓取不能碰撞下层货物。
5. **动态风险**：抓取过程中货物重心可能变化（液体晃动、内部摩擦滑动）。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | 🟡 2 | 顶部平整且无悬挑 | 悬挑件不适用 |
| B 夹爪 | 🟡 2 | 通用但需力控 | 力控参数难调 |
| C 插齿托举 | 🟢 3 | 托盘单元 | 非托盘件不适用 |
| D 复合 | 🟢 3 | 关键方案 | 强需求 |
| E 链路 | 🟡 2 | — | WMS 排序 + 重心估计是核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合 + C 托举优先**（托举从底部托起，避免悬挑倒塌连锁）。
- **关键改造**：
  - **6 维力/力矩传感器**（末端）+ 整机 IMU + 实时动力学模型。
  - **双臂协调托举**（一臂夹持一臂托举，最大化接触面积）。
- **链路 E**：
  - **WMS 预排序**：从顶层到下层、从外向内、从稳定到不稳定的优先级。
  - **在线重心估计**：多视角点云 + 抓取前力试探。
  - **风险预判**：抓取后预测货物侧翻概率，> 阈值切换为兜底平台。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| 悬挑件倒塌 | 高 | 双臂协调 + 兜底平台 |
| 重心偏移侧翻 | 高 | 6 维力控 + 整机重心补偿 |
| 力控失效 | 中 | 力试探 + 多视角复核 |
| 抓取顺序错误 | 中 | WMS 重排序 + 重试策略 |

**备选**

- **D 复合 + 兜底平台**：末端夹持后下方升起兜底平台托住悬挑。
- **人工 + 力控辅助**：高风险件人工介入。

**关键指标（KPI）**
- 重心估计误差：≤ 5cm（xyz）
- 悬挑件抓取成功率：≥ 92%
- 整机侧翻：0 次/千件
- 力控响应时延：≤ 50ms

#### 2.1.7 破损 / 渗漏 / 有残留

**定义**
集装箱内货物存在破损箱、有液体渗漏、地面有残留物（碎屑、漏液、粉末）。机器人需在不污染其他货物与下游设备的前提下完成抓取与清残。

**难点**
1. **污染扩散**：破损件抓取时液体/粉末扩散到其他货物。
2. **二次污染**：机器人末端接触渗漏物后再接触其他货物。
3. **地面残留**：机器人底盘/关节接触残留物（液体、腐蚀物）导致损坏。
4. **破损件形变**：结构受损，常规抓取点失效。
5. **处置路径**：破损件需专门处置（隔离区 / 收集槽），不能进入正常下游。

| 方案 | 可行性 | 适配货物 | 限制 |

| B 夹爪 | 🟡 2 | 形变件可夹持 | 接触式易污染 |
| C 插齿托举 | 🟡 2 | 托盘/底板单元 | 同 2.1.6 |
| D 复合 | 🟢 3 | 关键方案 | 配合隔离区使用 |
| E 链路 | 🟢 3 | — | 隔离区/收集槽/二次处置是核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合 + B 夹爪（一次性末端套）**。
- **关键改造**：
  - **末端一次性保护套**（无纺布/塑料膜卷），每次抓取自动更换。
  - **底盘防腐涂层 + IP67 关节**。
  - **6 维力控 + 力试探**，避开软塌区。
- **链路 E**：
  - **隔离区**：箱门口设隔离托盘，破损/渗漏件直接放入，由专人处置。
  - **收集槽**：地面漏液自动抽吸（机器人入口设 V 形槽 + 抽吸泵）。
  - **WMS 异常上报**：检测到破损/渗漏自动上报 + 工单派发。
  - **二次处置链**：隔离区 → 评估 → 报废 / 修复 / 转移处置区。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|

#### 2.1.8 危险品 / 爆炸品 / 腐蚀品（UN 分类 1~9 类）

**定义**
UN 分类危险货物：爆炸品（Class 1）、气体（Class 2）、易燃液体（Class 3）、易燃固体（Class 4）、氧化物/有机过氧化物（Class 5）、毒害品（Class 6）、放射性物质（Class 7）、腐蚀品（Class 8）、杂类危险品（Class 9）。作业须符合《国际海运危险货物规则》（IMDG）和《危险化学品安全管理条例》。

**难点**
1. **法规合规**：IMDG / GHS / OSHA 标准，全程可追溯（批次、接触人员、温湿度）。
2. **爆炸/火灾风险**：Class 1（爆炸品）、Class 3（易燃液体）需全链路防爆。
3. **腐蚀/毒害**：Class 6/8 货物对机器人末端、关节、底盘有强腐蚀性。
4. **泄漏处置**：一旦泄漏需立即隔离，不能污染其他货物与设备。
5. **人员安全**：作业区需实时有毒气体/可燃气体监测，机器人需支持远程操控。
6. **认证要求**：机器人本体及配套设备需 ATEX / IECEx / UL 认证。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | ⚪ 0 | 不适用 | 吸盘密封失效风险极高 |
| B 夹爪 | 🟡 2 | 固态 Class 8 腐蚀品（带防腐涂层） | Class 1/3/6 不适用 |
| C 插齿托举 | 🟡 1 | 固态 Class 8（托盘上） | Class 1/3/6/7 不适用 |
| D 复合 | 🟡 2 | 关键方案（防爆防腐改造版） | 改造复杂，成本极高 |
| E 链路 | 🟢 3 | — | 防爆工位 / 气体监测 / 隔离系统是核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合（防爆防腐改造）+ B 夹爪（防腐涂层 + 力控）**。
- **强制改造**：
  - ATEX Zone 1/2 认证电机 + 防爆接线盒。
  - IP67 防腐关节 + 关节防腐涂层（聚四氟乙烯/陶瓷）。
  - 末端防腐涂层（钛合金/哈氏合金 + 橡胶密封）。
  - 力控 + 远程操控（遥控，减少人员暴露）。

  - **防爆工位**：独立防爆围栏 + 正压通风 + 防爆照明。
  - **气体监测系统**：可燃气体探测器（LEL）+ 有毒气体检测仪（O₂/CO/H₂S）+ 实时联动。
  - **隔离与处置系统**：泄漏收集槽 + 中和剂自动喷洒 + 应急切断阀。
  - **法规合规记录**：WMS 全程批次追踪 + 操作人员记录 + 温湿度日志。

| 泄漏扩散 | 极高 | 隔离区 + 中和剂 + 自动切断 |
| 人员中毒 | 极高 | 远程操控 + 正压防护 + 实时气体监测 |
| 法规违规 | 极高 | 合规认证 + 全程记录 + 定期审计 |

**备选**

- **人工 + 专用工具**：Class 1/3/6 强烈推荐人工。
- **人工 + 远控 D 复合**：Class 8/9 可用。

**关键指标（KPI）**
- 防爆等级：Ex d IIB/IC T4 或更高（按 Class 分区）
- 防腐寿命：≥ 5000h（盐雾测试）
- 泄漏检测响应：≤ 5s
- 法规合规记录覆盖率：100%

#### 2.1.9 化工品（液体 / 粉末 / 固液混合）

**定义**
化工原料、医药中间体、涂料、油墨、树脂、胶黏剂等。形态涵盖液体（桶装/罐装）、粉末（袋装/桶装）、固液混合（反应釜原料）。部分化工品有挥发性、腐蚀性、易燃性。

**难点**
1. **挥发性与可燃性**：有机溶剂类化工品（苯/甲苯/丙酮）蒸气与空气混合后爆炸下限低。
2. **腐蚀性**：强酸（硫酸/盐酸）、强碱（氢氧化钠）、氧化剂（过氧化氢）腐蚀金属。
3. **固液混合**：反应釜原料可能为浆料/膏体，粘稠抓取困难。
4. **残留与交叉污染**：化工品不能残留于末端，否则交叉污染下游。
5. **气味与毒性**：挥发性有机物（VOC）对人员有害，需正压防护。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | ⚪ 0 | 不适用（粉末/液体污染吸盘） | 几乎不可行 |
| B 夹爪 | 🟡 2 | 固态化工品（防腐涂层 + 力控） | 液体/浆料受限 |
| C 插齿托举 | 🟡 2 | 桶装/IBC 吨桶化工品 | 需防腐叉型 |
| D 复合 | 🟢 3 | 关键方案（防腐防爆改造） | 改造复杂 |
| E 链路 | 🟢 3 | — | 防腐工位 / VOC 监测 / 清洗系统是核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合（防腐改造）+ C 叉型（防腐涂层，桶装/IBC）**。
- **强制改造**：
  - 末端防腐涂层（哈氏合金/PTFE）+ 密封等级 IP67。
  - 液体化工品：专用防滴落夹爪 + 底部集液槽。
  - 粉末化工品：末端负压除尘（收集泄漏粉末）+ 防静电设计。
  - 力控 + 慢速操作（减少液体晃动/粉末扬起）。
- **链路 E**：
  - **防腐工位**：耐腐蚀地面（环氧树脂）+ 围堰 + 独立通风。
  - **VOC/有毒气体监测**：PID 光离子化检测器 + 联动排风。
  - **自动清洗系统**：末端使用后自动冲洗（去离子水/中和剂）。
  - **WMS 合规追踪**：批次号 + MSDS（材料安全数据表）推送 + 处置记录。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| 爆炸/火灾（可燃液体） | 极高 | 防爆认证 + VOC 监测 + 通风 |
| 腐蚀损坏 | 极高 | 防腐涂层 + 定期检查 |
| 液体泄漏扩散 | 高 | 防滴落夹爪 + 集液槽 + 中和剂 |
| 粉末扬起 | 高 | 末端负压除尘 + 慢速操作 |
| 交叉污染 | 高 | 自动清洗 + 批次隔离 |

**备选**

- **人工 + 防腐工具**：强酸/强碱/高VOC 强烈推荐人工。
- **人工 + 远控 D 复合**：中等危害化工品可用。

**关键指标（KPI）**
- 防腐等级：SS316L 或哈氏合金
- VOC 响应浓度：≤ 10ppm（实时联动）
- 交叉污染率：0
- 清洗系统出水水质：pH 中性（6~8）

### 2.2 散货场景

#### 2.2.1 袋装（编织袋 / 牛皮纸袋 / 吨袋）

**定义**
散装袋装货物：编织袋（PE/PP，5~50kg）、牛皮纸袋（化工/水泥，25~50kg）、吨袋（FIBC，500~1500kg）。作业终点为传送带 / AGV / 暂存区。

5. **破袋风险**：抓取力过大易破袋，液体/粉末泄漏。

| C 插齿托举 | ✅ 4 | 吨袋（叉型从底部托起）+ 编织袋（托盘上时） | 单袋无托盘时插齿难入 |
| D 复合 | ✅ 4 | 任意（关键方案） | 必备 |
| E 链路 | ✅ 4 | — | 传送带 / 吨袋吊装工位 |

**推荐组合（含本体 + 配套链路）**

- **本体**：

- **关键改造**：
  - 夹爪防滑齿（橡胶包覆 + 锯齿纹）。
  - 力控阈值可调（按袋装满度动态调整）。
  - 吨袋专用吊带抓取器（4 点吊带，自动找平）。
- **链路 E**：
  - **传送带同步**：袋装入传送带时缓冲对齐（避免撞击）。
  - **吨袋吊装工位**：专用吊车/桁架与机器人协同。
  - **WMS 推送 SKU + 重量 + 满度标识**。

**风险与降级**

| 风险 | 等级 | 降级路径 |

| 吨袋吊装失衡 | 高 | 4 点找平 + IMU 反馈 |
| 半袋/塌袋 | 中 | 切换托举 + 双臂抱夹 |

**备选**

- **D 复合 + 真空吸附（顶面）**：袋装顶面平整时高节拍方案。
- **C 托举专用机**：吨袋专用场景。

**关键指标（KPI）**

- 破袋率：≤ 0.5%
- 传送带对接精度：±30mm

#### 2.2.2 箱装（瓦楞纸箱 / 蜂窝板箱 / 塑料周转箱）

**定义**
箱装货物：瓦楞纸箱（≤ 30kg，常见电商/物流）、蜂窝板箱（≤ 50kg，重型）、塑料周转箱（≤ 25kg，可循环）。作业终点为传送带 / AGV / 立体库。

#### 2.2.5 颗粒散货（粮食 / 化肥 / 饲料）颗粒级

颗粒级散货：粮食（小麦/玉米/大豆，袋装或散装）、化肥（颗粒/粉末袋装）、饲料（颗粒袋装）。本节特指**颗粒袋装**场景（散装箱场景见 2.1.5）。

| 方案 | 可行性 | 适配货物 | 限制 |

  - **防爆工位**：作业区域独立通风 + 浓度监测。

#### 2.2.9 冷链箱装（低温冷藏品）

**定义**
冷链箱装货物：冷冻食品（肉/鱼/冰淇淋，-18°C）、冷藏食品（乳制品/果蔬，0~8°C）、医药品（疫苗/血液制品，2~8°C）、恒温恒湿品（红酒/精密仪器，15~25°C）。货物形态为瓦楞箱/泡沫箱/塑料箱，内含保温材料。

**难点**
1. **温控完整性**：箱内温度需全程维持，冷链断链后货物价值归零。
2. **冷凝水打滑**：冷藏品出库后表面快速结露，夹爪/吸盘均会打滑。
3. **保温包装变形**：泡沫箱（EPS/XPS）质地软、易碎，受压变形。
4. **码放紧密**：冷链货物为最大化冷库空间往往码放紧密，抓取间隙小。
5. **冷库作业环境**：低温导致机器人关节润滑脂凝固、电子元件低温漂移。
6. **卫生要求**：食品/医药冷链有 HACCP / GMP 要求，机器人末端需食品级/医疗级材料。

**横向对比**

| 方案 | 可行性 | 适配货物 | 限制 |
|------|:---:|------|------|
| A 负压 | 🟡 2 | 干态平整塑料箱 | 冷凝水打滑；食品级材料难保证 |
| B 夹爪 | 🟢 3 | 食品级夹爪（带防滑纹） | 需食品级认证；冷凝水导致打滑 |
| C 插齿托举 | 🟢 3 | 托盘单元冷链箱 | 无托盘单件受限 |
| D 复合 | ✅ 4 | 任意（关键方案） | 需食品级认证 + 低温改造 |
| E 链路 | ✅ 4 | — | 冷链监控 / 温控传送 / 卫生标准是核心 |

**推荐组合（含本体 + 配套链路）**

- **本体**：**D 复合 + B 夹爪（食品级 + 力控 + 防滑纹）** + A 吸盘（平整塑料箱备选，食品级硅胶）。
- **强制改造**：
  - **食品级/医疗级材料**：末端不锈钢（SS304/SS316L）+ 食品级硅胶密封。
  - **低温润滑**：关节低温润滑脂（-40°C 适用）+ 电机预热。
  - **防冷凝**：末端加热带（防结冰）+ 低速操作（减少冷凝）。
  - **力控精细**：食品箱抗压 5~15kg/cm²，力控阈值需精确（防压溃）。
- **链路 E**：
  - **温控传送带**：保温传送带（内嵌制冷管/相变材料），维持 0~8°C。
  - **冷链监控**：IoT 温度传感器（精度 ±0.5°C）+ 全程数据记录（FDA 21 CFR Part 11）。
  - **卫生标准**：HACCP / GMP 认证地面（不锈钢）+ 自动清洗（CIP）。
  - **WMS 合规追踪**：冷链全程温度日志 + 批次号 + 有效期管理。

**风险与降级**

| 风险 | 等级 | 降级路径 |
|------|:---:|------|
| 冷链断链 | 极高 | 温控传送带 + 全程监控 |
| 冷凝水导致打滑 | 高 | 末端加热带 + 食品级防滑纹 |
| 食品箱压溃 | 高 | 力控精细 + 软垫夹爪 |
| 低温关节失效 | 高 | 低温润滑 + 预热 + 备机轮换 |
| 卫生污染 | 极高 | 食品级材料 + CIP 自动清洗 |

**备选**

- **D 复合（食品级改造）**：全线食品级认证，含末端 CIP 自动清洗。
- **人工 + 远控 D 复合**：高价值医药冷链强烈推荐。

**关键指标（KPI）**
- 全程温控精度：±1°C（符合 WHO/GDP 要求）
- 食品级认证：FDA 21 CFR / EU GMP

- 冷链断链次数：0 次/千件

| 参数 | 规格 |
|------|------|
| 抓取原理 | 插齿（叉型入孔）/ 抱夹（双臂从两侧或上下）/ 托举（底部托起） |
| 单件最大重量 | 标准型 ≤ 2t；重载型 ≤ 10t（叉车型） |
| 抓取节拍 | ≤ 6s/件（叉型入孔） |
| 适用 | 托盘单元、底部有承载面、有叉孔的货物 |
| 不适用 | 软质无托盘、零散单件 |
| 叉型长度 | 800mm ~ 2400mm（可调） |
| 抱夹行程 | 600mm ~ 2200mm |
| 抱夹力 | 0.5 ~ 5t 连续可调 |
| 力反馈 | 6 维力/力矩传感器 + IMU |

#### 3.3.2 子型谱

| 子型 | 适用场景 | 关键参数 |
|------|---------|---------|
| C1 标准叉型 | 欧/美/田/川托盘 | 长度 1100/1200mm，宽度 100~180mm |
| C2 加长叉型 | 长板条/型材 | 长度 2400mm |
| C3 加宽叉型 | IBC 吨桶 | 宽度 200mm，长度 1200mm |
| C4 双臂抱夹 | 软包/袋装 | 双臂间距 600~2200mm，行程 600mm |
| C5 上下抱紧 | 箱装/袋装 | 上下夹板 + 压紧力可调 |
| C6 底部托举 | 软包/纤维/液体袋 | 托举平台 + 防滑表面 |
| C7 龙门吊式抱夹 | 卷钢/超大件 | 10t+ 龙门吊协同 |

#### 3.3.3 边界与失败模式

- **叉型插入失败**：托盘变形/叉孔偏差 → 视觉自适应 + 多次尝试 + 切夹爪。
- **抱夹失衡**：重心偏移 → 6 维力反馈 + IMU 找平。
- **托举打滑**：软包/液体袋 → 防滑表面 + 大接触面。
- **叉型磨损**：长期使用磨损 → 定期更换 + 视觉磨损检测。

#### 3.3.4 与其他类组合建议

- C + A：整托托举 + 单件吸盘定位。
- C + B：整托托举 + 单件夹爪精抓。
- C + A + B：完整的复合式 D。

---

### 3.4 D 类：复合式（≥2 种融合 / 双臂协调 / 快换末端）

#### 3.4.1 总体规格

| 参数 | 规格 |
|------|------|
| 集成方式 | ≥2 种融合（吸盘+夹爪+叉型任意组合）/ 双臂协调 / 快换末端 |
| 末端数 | 单末端多功能（≥2 功能合一）/ 双臂（每臂独立末端） |
| 快换时间 | ≤ 3s（电动快换） / ≤ 10s（手动快换） |
| 双臂协调 | 同步精度 ±1mm（高速）/ ±5mm（低速重载） |
| 最大总载重 | 双臂合计 ≤ 1t（协作型） / ≤ 5t（重载型） |
| 适用场景 | 任意（高度异构场景首选） |
| 成本 | 显著高于单一类型 |

#### 3.4.2 子型谱

| 子型 | 适用场景 | 关键参数 |
|------|---------|---------|
| D1 双末端快换（吸盘+夹爪） | 多 SKU 箱装/袋装 | 快换时间 ≤ 3s |
| D2 双末端快换（夹爪+叉型） | 托盘单元 + 单件 | 兼容托盘 + 散件 |
| D3 三合一快换（吸盘+夹爪+叉型） | 通用多 SKU | 全场景 |
| D4 双臂协调 | 偏载/悬挑/异形 | 双臂同步 ±1mm |
| D5 双臂 + 龙门协同 | 长件/超大件 | 双机器人 + 龙门 |
| D6 多末端融合（单末端多模） | 紧凑型 | 单末端 2~3 种功能 |
| D7 多末端融合（双臂 + 末端工具库） | 全场景 | 末端自动仓库 |

#### 3.4.3 边界与失败模式

- **快换失效**：定位偏差 → 视觉校准 + 力反馈。
- **双臂冲突**：运动轨迹冲突 → 运动规划避让 + 优先级管理。
- **集成复杂度高**：维护成本高 → 模块化设计 + 远程诊断。
- **成本高**：单一场景不划算 → 仅多 SKU / 高异构场景适用。

#### 3.4.4 推荐场景

- **D1**：电商多 SKU 仓库（兼容箱装 + 袋装）
- **D2**：托盘 + 散件混合场景
- **D3**：通用多 SKU 全场景
- **D4**：偏载 / 悬挑 / 异形（2.1.6、2.2.8）
- **D5**：超长件 / 超重件（2.2.6、2.2.8）
- **D6**：紧凑作业空间（箱内）
- **D7**：多 SKU 自动化产线

| 阶段 | 名称 | 周期 | 关键里程碑 |

### 3.5.2 各阶段详细说明

#### 阶段 0：商务与可行性论证（Week 1~4）

**工作内容**
- 需求调研：货品类型/包装规格/节拍要求/作业环境。
- 场景适配分析：按第 1/2 章场景分类匹配机器人方案。
- 可行性报告：技术可行性 + 经济可行性。
- 合同签署与技术方案确认。

**交付物**
- 需求规格说明书（SRS）
- 可行性论证报告
- 技术方案初版（含机器人类型与链路配置）

#### 阶段 1：详细设计（Week 5~12）

**工作内容**
- 机器人详细选型：机械臂型号/末端执行器规格。
- 运动学仿真：基于 Gazebo + MoveIt! 验证臂展与节拍。
- 感知方案设计：2D/3D 视觉选型 + 算法选型。
- 调度系统架构设计：WMS 接口 + AGV 调度。
- 安全评估：风险评估报告（符合 ISO 13849）。
- 详细设计评审（CDR）。

**交付物**
- 详细设计文档（含 BOM）
- 仿真验证报告
- 安全评估报告
- CDR 评审纪要

#### 阶段 2：采购与预组装（Week 13~20）

**工作内容**
- 机器人本体采购（交付周期 8~16 周）。
- 末端执行器定制（交付周期 4~8 周）。
- 配套链路设备采购（传送带/AGV/WMS）。
- 预组装：在厂内完成机器人 + 末端 + 控制柜集成。
- 厂内功能测试（单机动作测试）。

**交付物**
- 厂内测试报告
- 设备到货清单
- 预组装记录

#### 阶段 3：现场部署与调试（Week 21~28）

**工作内容**
- 现场改造：地面平整/电气接入/网络安全。
- 机器人安装：吊装/定位/电气连接。
- 单机调试：原点标定/坐标系建立/关节限位。
- 末端调试：吸盘/夹爪/叉型功能测试。
- 视觉系统标定：相机内外参标定。
- 单机节拍测试。

**交付物**
- 现场调试报告
- 单机节拍测试记录（≥ 目标值）

#### 阶段 4：系统集成测试（Week 29~36）

**工作内容**
- 链路对接：传送带同步/AGV 调度/WMS 接口联调。
- 多机协同（双臂/多机）：同步精度测试。
- 安全系统验证：急停/区域扫描/力控测试。
- 异常场景测试：破损/渗漏/偏载场景演练。
- 全链路联调：机器人 → 传送带/AGV → WMS 全流程测试。
- 压力测试：连续 24h 运行。

**交付物**
- 集成测试报告
- 压力测试报告
- 安全验证报告

#### 阶段 5：试运行与优化（Week 37~44）

**工作内容**
- 72h 连续运行（模拟正式作业）。
- 节拍优化：轨迹规划/视觉算法/调度参数调优。
- KPI 验收：按第 2 章各场景 KPI 逐项验证。
- 异常处理流程验证。
- 操作人员培训（现场 + 远程）。

**交付物**
- 72h 运行报告
- KPI 验收报告
- 培训记录

#### 阶段 6：正式投产与移交（Week 45~48）

**工作内容**
- 正式投产（Production Release）。
- 文档移交：操作手册/维护手册/备件清单。
- 运维交接：运维团队培训 + 值班安排。
- 质保期开始。

**交付物**
- 运维文档包
- 验收证书
- 项目总结报告


## 3.7 场景易实现性评估

> 本章从 18 个场景中按"方案成熟度 / 技术风险 / 改造成本 / 集成复杂度 / 法规障碍"5 个维度评估，得出"最容易实现"的 Top 3 场景与完整 18 场景排名。
> 适合作为**优先落地项目**与**试点选型**的决策参考。

### 3.7.1 评估维度

| 维度 | 权重 | 评分标准 |
|------|:---:|---------|
| **方案成熟度** | 25% | 商业化案例数量、行业标准、厂商生态 |
| **技术风险** | 25% | 传感器/算法/控制成熟度、研发周期 |
| **改造成本** | 20% | 是否需要防爆/防腐/低温/食品级等重型改造 |
| **集成复杂度** | 15% | WMS/AGV/传送带对接难度 |
| **法规障碍** | 15% | 认证/合规要求（ATEX/GMP/HACCP 等） |

> 评分采用 1~10 分制，**分数越高越容易实现**。

### 3.7.2 最容易实现的场景 Top 3

#### 🥇 第 1 名：2.2.7 托盘单元（标准欧/美/田/川）— 9.5/10

| 维度 | 评分 | 理由 |
|------|:---:|------|

## 4. 配套链路设施详细规格（E 类）

> 本章为 E 类配套链路设施的详细规格，含传送带对接 / AGV 入仓 / WMS / 任务调度等。
> 链路设施不属于机器人本体，但是机器人正常运行的必要条件。

### 4.1 E-1 传送带对接系统

#### 4.1.1 总体规格

| 参数 | 规格 |
|------|------|
| 类型 | 辊道式 / 皮带式 / 链板式 |
| 节拍范围 | 5 ~ 30 件/min |
| 对接精度 | ±5mm（机器人放置）/ ±10mm（上游供给） |
| 速度 | 0.1 ~ 2 m/s 可调 |
| 通信 | Profinet / EtherCAT / OPC UA |
| 同步方式 | 节拍同步（脉冲）/ 事件同步（消息） |

#### 4.1.2 关键模块

- **同步控制器**：与机器人节拍同步，下游堵塞时机器人进入 摆动暂存。
- **位置检测**：光电开关 / 视觉定位 / RFID。
- **缓冲段**：短传送带 + 摆动臂 + 临时缓存（应对节拍波动）。
- **安全围栏**：光幕 + 安全 PLC，符合 ISO 13849。

#### 4.1.3 与机器人接口

- 机器人 → 传送带：放置完成信号 + 节拍请求。
- 传送带 → 机器人：节拍可用信号 + 速度反馈 + 异常报警。
- 协议：OPC UA Pub/Sub 或自定义 JSON-RPC。

#### 4.1.4 适用场景

- 2.1.1 / 2.1.3 / 2.2.1 / 2.2.2 / 2.2.3 / 2.2.4（袋装 / 箱装 / 桶装 / 软包入传送带）

---

### 4.2 E-2 AGV 入仓系统

#### 4.2.1 总体规格

| 参数 | 规格 |
|------|------|
| 类型 | 潜伏式 AGV / 叉车 AGV / 复合机器人 AGV |
| 负载 | 100kg ~ 5t |
| 导航 | 二维码 / SLAM / 视觉 / 毫米波雷达 |
| 定位精度 | ±10mm（停车）/ ±5mm（二次校准后） |
| 通信 | 5G / Wi-Fi 6 / 工业以太网 |
| 调度协议 | VDA 5050 / 自定义 |

#### 4.2.2 关键模块

- **AGV 调度系统**（Fleet Management）：
  - 任务队列 + 路径规划 + 避让算法。
  - 多 AGV 协同（同向/对向/交叉避让）。
  - 电量管理 + 自动充电。
- **对接工位**：
  - 停车定位（精度 ±10mm）。
  - 视觉二次校准（精度 ±5mm）。
  - 安全围栏 + 急停。
- **异常接管**：
  - AGV 故障检测。
  - 自动重派 / 临时缓冲区。
  - WMS 工单上报。

#### 4.2.3 与机器人接口

- WMS → AGV 调度：任务（取货位 + 放货位 + SKU + 优先级）。
- AGV → 机器人：到位信号 + 位姿反馈。
- 机器人 → AGV：放置完成信号。
- 协议：VDA 5050 / ROS2 / 自定义。

#### 4.2.4 适用场景

- 2.1.2（标准掏箱→AGV入仓）/ 2.1.5（装箱时 AGV 跟随）/ 2.2.7（托盘放 AGV 入立体库）

---

### 4.3 E-3 WMS（仓库管理系统）接口

#### 4.3.1 总体规格

| 参数 | 规格 |
|------|------|
| 功能 | SKU 管理 / 库位管理 / 任务调度 / 异常上报 / 报表 |
| 接口协议 | RESTful API / WebSocket / 数据库直连 / ROS2 topic |
| 数据格式 | JSON / Protobuf / 自定义 XML |
| 时延 | 推送时延 ≤ 200ms |
| 同步 | 双向同步（push / pull） |

#### 4.3.2 关键数据流

- WMS → 机器人：
  - 任务列表（SKU、源、目的、优先级、特殊约束）。
  - SKU 元数据（尺寸、重量、易碎、堆叠规则、危险品）。
  - 库位推荐（基于实时库存）。
- 机器人 → WMS：
  - 任务执行状态（开始 / 完成 / 失败 / 异常）。
  - 异常上报（破损 / 渗漏 / 视觉异常）。
  - 节拍统计 / KPI 上报。

#### 4.3.3 异常处理流程

1. 机器人检测到异常 → 上报 WMS。
2. WMS 创建异常工单。
3. WMS 重排任务 + 派发备员（如需要）。
4. 机器人继续执行其他任务或暂停等待。

#### 4.3.4 适用场景

- 所有场景（WMS 是基础链路）

---

### 4.4 E-4 任务调度系统

#### 4.4.1 总体规格

| 参数 | 规格 |
|------|------|
| 功能 | 任务规划 / 资源分配 / 实时调度 / 死锁检测 |
| 调度对象 | 机器人 / AGV / 龙门吊 / 传送带 / 隔离工位 |
| 调度算法 | 基于约束满足（CSP）/ 启发式 / 强化学习 |
| 调度粒度 | 单任务 / 批次 / 全局 |
| 实时性 | 决策时延 ≤ 500ms |

#### 4.4.2 关键模块

- **任务规划器**：
  - 短期规划（≤ 5min）：基于实时状态。
  - 中期规划（≤ 30min）：基于 WMS 任务队列。
  - 长期规划（≤ 24h）：基于入库计划。
- **资源分配器**：
  - 机器人-任务匹配（基于末端类型 / 位置 / 电量）。
  - AGV-任务匹配（基于位置 / 电量 / 容量）。
- **实时调度器**：
  - 任务优先级管理。
  - 紧急插队（如破损/渗漏隔离）。
  - 死锁检测与恢复。
- **数字孪生**：
  - 实时仿真（预测节拍）。
  - 瓶颈分析。

#### 4.4.3 适用场景

- 所有场景（尤其是 2.1.5 装箱 / 2.1.6 偏载 / 2.1.7 破损 / 2.2.8 异形件）

### 4.5 E-5 视觉与感知系统

#### 4.5.1 总体规格

| 参数 | 规格 |
|------|------|

- **抓取点预测**：GraspNet / 6-DoF GraspNet / Dex-Net。

#### 4.5.3 适用场景

- 所有场景（视觉是机器人眼睛）
