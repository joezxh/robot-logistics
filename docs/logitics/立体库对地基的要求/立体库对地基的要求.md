# 立体库对地基的要求

均匀承载：立体库通常存放大量货物，货架高度较高，货物重量大，因此要求地 基有足够的承载力来均匀承受整个立体库的重量，包括货架、货物以及可能产生的动 荷载等。一般来说，需要根据立体库的设计荷载，通过地质勘察确定地基土的承载能 力特征值，确保地基能够满足承载要求，防止出现不均匀沉降。

特殊区域加强：对于货架立柱等集中受力部位，地基的承载力要求更高。可能需 要对这些部位进行特殊的地基处理，如采用桩基础或加大基础尺寸等方式，以保证立 柱能够稳定支撑货架和货物重量。

稳定性要求。

抗水平荷载：立体库在使用过程中可能会受到风荷载、地震荷载等水平力的作 用，地基必须具备足够的稳定性来抵抗这些水平力，防止立体库发生整体倾斜或滑 移。在地震多发地区，地基的抗震性能尤为重要，需要根据当地的抗震设防烈度等要 求，对地基进行相应的抗震设计和处理。

防止土体液化：如果立体库建设在可能发生液化的地基土上，如饱和砂土或粉土 等，需要采取措施防止土体液化，如采用振冲法、强夯法等对地基进行加固处理，提 高土体的抗液化能力。

平整度要求。

保证货架安装精度：为了确保立体库货架的安装精度和稳定性，地基表面需要有 较高的平整度。一般要求地基表面的平整度偏差控制在一定范围内，如每平方米内的 平整度偏差不超过 3-5 毫米。如果地基平整度不满足要求，会导致货架安装不垂直， 影响货物的存储和堆垛机等设备的运行，甚至可能造成安全隐患。

利于物流设备运行：平整的地基对于堆垛机、输送机等物流设备的正常运行也至 关重要。不平整的地基会使设备运行时产生颠簸、振动，增加设备的磨损和故障概 率，降低物流作业的效率和准确性。

沉降控制要求。

严格控制总沉降量：立体库的地基沉降量必须控制在允许范围内，一般要求总沉 降量不超过 50-100 毫米，具体数值根据立体库的规模、高度和使用要求等确定。过大 的沉降会导致货架变形、货物堆放不整齐，甚至可能使货架结构受损，影响立体库的 正常使用。

控制不均匀沉降：不均匀沉降对立体库的危害更大，可能导致货架倾斜、梁柱连 接破坏等问题。因此，需要通过合理的地基处理和基础设计，将不均匀沉降控制在极 小范围内，一般要求相邻柱基之间的沉降差不超过 2-3 毫米。

其他要求。

耐久性要求：地基应具有良好的耐久性，能够抵抗地下水、土壤中的化学物质等 的侵蚀，保证地基在立体库的使用年限内保持稳定的性能。

地质条件要求：建设立体库前，需要对场地的地质条件进行详细勘察，确保地基 土中不存在暗浜、溶洞、古墓等不良地质现象。如果存在这些问题，需要在施工前进 行妥善处理，如对暗浜进行换填、对溶洞进行填充等，以保证地基的均匀性和稳定 性。
