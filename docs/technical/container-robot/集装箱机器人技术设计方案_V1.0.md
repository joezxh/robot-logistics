## 1 项目概述与技术路线选择

### 1.1 项目背景

本项目旨在开发一套用于室内仓储物流和电商分拣场景的集装箱装卸机器人系统。根据前期需求分析，项目具有以下特点：

- **应用场景**：室内仓储 + 电商分拣柔性产线
- **负载需求**：100-500kg（中型方案），兼顾标准集装箱吞吐
- **精度要求**：定位精度 ±2-3mm，重复精度 ±1mm
- **时间约束**：6个月内完成样机验证
- **预算范围**：200-500万（高性能优先）

### 1.2 技术路线决策

经过方案比选，本项目采用 **"采购成熟平台 + 自研软件与应用层"** 的技术路线。

#### 1.2.1 路线选择依据

| 考量因素 | 分析结论 |
|---------|---------|
| 时间约束 | 6个月内完成样机，自研机械本体周期过长（通常12-18个月） |
| 预算充足 | 可采购高端工业机器人平台，确保性能指标达成 |
| 核心能力 | 软件算法是差异化竞争的核心，应作为自研重点 |
| 风险控制 | 成熟平台可靠性高，减少调试周期和故障风险 |

#### 1.2.2 平台选型原则

选用国际一线品牌的标准工业机器人平台作为运动执行层，原因如下：

1. **性能可靠**：定位精度、重复精度、运动速度均达到规格要求
2. **生态成熟**：配套的离线编程、仿真、调试工具完善
3. **安全认证**：符合ISO 10218-1/2工业机器人安全标准
4. **服务网络**：国内有完整的售后服务和技术支持体系

#### 2.3.2 各执行器详细设计

**（1）托盘夹具（自研）**

| 组件 | 规格 | 选型/来源 |
|------|------|----------|
| 夹指 | 高强度铝合金+聚氨酯包覆 | 自研设计，铝型材定制 |
| 驱动 | 液压油缸（双作用） | 海德福斯/布赫（进口） |
| 液压站 | 3kW电机+叶片泵 | 国产（恒立/榆次） |
| 液压阀 | 比例阀+电磁阀组 | 派克/力士乐（进口） |
| 传感器 | 夹紧力传感器×4 | Tecsis（进口） |
| 快换机构 | ISO 9409-1-63-4-M6 | 雄克（进口） |

**自研必要性**：夹具设计需根据实际托盘尺寸定制，快换机构是差异化功能，自研可降低成本并掌握核心接口标准。

**（2）真空吸盘阵列（自研+采购）**

| 组件 | 规格 | 选型/来源 |
|------|------|----------|
| 吸盘 | 食品级硅胶，φ80/φ120mm | Telsonic（进口） |
| 真空发生器 | 10-50kPa可调 | SMC/费斯托（进口） |
| 真空开关 | 数字式，精度±1kPa | 宜科（国产） |
| 控制阀 | 24V电磁阀，响应<20ms | 亚德客（国产） |
| 管路 | PU管+快速接头 | 国产 |

**自研必要性**：吸盘阵列的布局和真空系统设计需匹配具体货物规格，自研可灵活调整。

**（3）叉型执行器（采购为主）**

| 组件 | 规格 | 选型/来源 |
|------|------|----------|
| 叉体 | 整体焊接结构，承载3t | 科力（国产） |
| 驱动 | 液压或电动 | 国产 |
| 快换接口 | 兼容本系统快换机构 | 自研 |

**采购原因**：叉型执行器结构标准化，市面产品成熟，直接采购性价比更高。
