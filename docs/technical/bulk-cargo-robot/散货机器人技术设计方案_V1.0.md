## 1 项目概述与技术路线选择

### 1.1 项目背景

本项目旨在开发一套用于室内仓储物流和电商分拣场景的散货分拣机器人系统。散货场景的特点是货物形态多样（纸箱、软包、小件）、重量较轻（1-50kg）、分拣精度要求高。

| 需求维度 | 具体要求 |
|---------|---------|
| **应用场景** | 室内仓储 + 电商分拣柔性产线 |
| **负载需求** | 3-30kg（散货单件重量） |
| **精度要求** | 定位精度 ±1mm，重复精度 ±0.5mm |
| **时间约束** | 6个月内完成样机验证 |
| **预算范围** | 200-500万（高性能优先） |
| **技术策略** | 采购核心部件 + 自主集成 |

### 1.2 技术路线决策

根据项目特点（柔性产线、多品种混线、6个月周期），本项目采用 **"国产协作平台 + 自研全套应用层"** 的技术路线。

#### 1.2.1 路线选择依据

| 考量因素 | 分析结论 |
|---------|---------|
| **负载匹配** | 散货重量1-50kg，协作机器人完全满足，无需大型工业机器人 |
| **灵活性** | 协作机器人支持拖动示教、快速换型，适合柔性产线 |
| **自研深度** | 采用协作平台可自研机械本体（末端执行器）和全栈软件 |
| **供应链** | 国产协作机器人供应链成熟，交货周期短（4-6周） |
| **成本效益** | 协作机器人性价比高，节省预算用于自研投入 |

#### 1.2.2 为什么不选择其他路线

| 路线 | 不采用原因 |
|------|----------|
| 全采购成熟平台 | 无法深入掌握核心技术，软件能力积累有限 |
| 自研机械本体 | 6个月周期紧张，机械设计+验证周期不足 |
| 重载工业机器人 | 散货分拣负载需求低，大马拉小车浪费资源 |

### 6.2 成本控制建议

1. **选用国产协作平台**：相比进口品牌，节省30-50%硬件成本
2. **复用开源框架**：基于ROS2、MoveIt、OpenCV等开源框架，降低开发成本
3. **自研末端执行器**：相比采购专用夹爪，节省50%成本
4. **分阶段采购**：核心设备先采购，非核心设备分批到位
