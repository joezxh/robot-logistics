# Development Notes — 2026-08-15

## Test runtime requirement: httpx 0.25.x

`starlette==0.27.0` (used by FastAPI 0.104 via `paho-mqtt`/`fastapi.testclient.TestClient`)
calls `httpx.Client(app=self.app, ...)` in its `TestClient.__init__` chain.
Starting with `httpx==0.28`, the `app` keyword was removed from `httpx.Client`,
breaking `from fastapi.testclient import TestClient; TestClient(app)` with
`TypeError: Client.__init__() got an unexpected keyword argument 'app'`.

**Mitigation in this branch**: pin `httpx==0.25.0` is already present in
`rcs/requirements.txt` and `simulation/backend/requirements.txt`. Keep it.
After a fresh `pip install -r requirements.txt`, if TestClient tests fail with
`unexpected keyword argument 'app'`, run:

```bash
python -m pip install "httpx<0.28"
```

The `unstructured-client` package in the global environment tries to upgrade
httpx past 0.28 — that is the source of the regression observed during
integration validation. New environments may want to add an environment-specific
constraint file (`requirements-frozen.txt`) or use `pip-compile` to lock httpx.

## Stale bytecode cache can reference deleted files

If a workspace path is renamed (e.g. `backend/` → `simulation/backend/`),
stale `__pycache__/*.pyc` files may still encode the old path. Pytest's
collection layer can pick them up and produce ghost failures such as
`FAILED ::test_devices_lists_seed at D:\projects\robot-logic\backend\tests\test_api.py:63`
even though that file no longer exists. Mitigation:

```bash
python -c "import pathlib, shutil; [shutil.rmtree(p, ignore_errors=True) for p in pathlib.Path('.').rglob('__pycache__')]"
```

This was needed once during Top 3 simulation plan verification and is worth
keeping in any test-run cookbook.
