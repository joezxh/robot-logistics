设计第 4 节：Web/前端交互与边缘视角

仓库视角 → 边缘视角跳转 · Gazebo + 点云 + 检测叠加 · 10 Hz 上限 · 二段确认。

A. 页面骨架
┌────────────────────────────────────────────────────────────────────┐ │ 顶栏：设备 · 任务 · 告警 · 日志 角色：operator | supervisor │ ├────────────────────────┬───────────────────────────────────────────┤ │ 设备列表 │ Three.js 仓库视角 │ │ · robot-01 ● │ · robot-01 / robot-02 / robot-03 │ │ · robot-02 ◐ │ · 点击设备 → 边缘视角 │ │ · robot-03 ○ │ · 浮动检测框 · 任务阶段标签 │ ├────────────────────────┴───────────────────────────────────────────┤ │ 日志抽屉（可收起）：告警 / 事件 / WS 状态 │ └────────────────────────────────────────────────────────────────────┘
B. 边缘视角布局
  • 左 70%：Gazebo 第一人称 + 点云 + 检测叠加（10 Hz 上限）
  • 右 30%：任务阶段时间线 + arm_state_mode + 限速 + 控制面板
  • 顶部状态条：连接质量 / 最近心跳 / 当前阶段
  • 底部：仅观察者模式下的“录制”按钮（仿真）
C. 控制面权限
observer : 看 — 无 operator : 看 + 下发任务 — PickPlace/Navigate/Pause/Resume supervisor:看 + 锁定设备 — 以上 + lock_device local_hmi : 急停/清零 — 本机，仅限急停面板
D. 下发任务流程（二段确认）
① 选择目标 + 放置区
② 勾选安全约束
③ “确认下发”按钮
④ UI 切到 “待接收”

Action 接收后 UI 推进阶段进度；任何异常状态会以 banner 形式呈现，30 s 内无反馈 → “连接弱” 黄色提示 + 上次状态快照。

E. WS 通道与重连
/ws/devices 设备总览（arm_state_mode · state · stage） /ws/edge/{id} 边缘视角（camera · 点云 · detection · scene） /ws/alerts 告警全局广播（与设备解耦） /ws/logs 审计日志（仅 supervisor 可见）
F. 渲染频率与降级
  • 边缘视角默认 10 Hz 上限；超载自动降到 5 Hz
  • 点位姿态仅推送增量（差分坐标），避免重复 6D 信息
  • 相机流优先保证：点云降级 → 检测降级
  • WS 失联 ≥30 s → 黄色提示 + 上次状态快照（不自动跳转）
