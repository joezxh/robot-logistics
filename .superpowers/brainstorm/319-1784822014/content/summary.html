5 节汇总 · Phase 5 设计结论

本地 HMI 胜出 · Gateway 只接任务级 Action · 阶段 11 状态机 · 边缘视角嵌入 · M0–M5 一步一验。

第 1 节：集成边界

  • Gateway 仅下发任务级 Action，不覆盖 ros2_control
  • Gazebo 与真实硬件共享 arm_hal 抽象，启动参数按设备 ID 选择
  • Web 实时状态：事件触发拉取 + 周期心跳

第 2 节：ROS2 接口契约

  • 包：robot_msgs / robot_bringup / robot_moveit_config / robot_gateway / robot_decision / robot_perception / robot_arm_hal
  • Action：PickPlace；MoveIt MoveGroup + ExecuteTrajectory
  • Topic：camera/* · /perception/* · /robot/state · /estop · /planning_scene_motion
  • TF：world → map → robot_base → arm_base → link1..6 → gripper_frame
  • QoS：BE 实时 / RV+TL 状态 / RV 关键指令

第 3 节：安全与恢复

  • 本地 HMI 严格胜出急停；仅本地可清除 e_stop
  • arm_state_mode 7 态，感知恢复采用联立采样保守策略
  • PickPlace 11 阶段，每阶段 pre_check/execute/post_check
  • 限速：1.0 m/s 全速，0.2 m/s 安全位置；0.25 m/0.5 m 限速阈值
  • 顶层调度抽象：PickPlace / Navigate / Pause / Resume（四 Action）

第 4 节：Web 交互与边缘视角

  • 页面骨架：Dashboard · TaskQueue · Alerts · LogViewer，沿用现有工程
  • 边缘视角：Gazebo 视频 + 点云 + 检测叠加，上限 10 Hz，自动降级
  • 权限：observer / operator / supervisor / local_hmi（仅本地清急停）
  • PickPlace 下发：二段确认（勾选约束 + 一键）
  • WS 通道：/ws/devices · /ws/edge/{id} · /ws/alerts · /ws/logs
  • supervisor 独占面板：PG/SQL 状态（只读）、手动 override（带审计日志）

第 5 节：里程碑与验收

  • M0–M5 顺次交付：骨架 → 机器人/仿真 → 感知 → 决策闭环 → Web Gateway → 演示验收
  • 每里程碑 1 个 verify_*.sh，进入 CI，验证脚本与代码同存
  • 度量：闭环 ≥ 90%、动作 ≤ 90 s、急停响应 ≤ 200 ms、WS 重连 ≤ 2 s 对齐
  • CI nightly 跑全链路，仅记录耗时与产出，不阻断 PR
  • 风险：URDF/SRDF 不一致、感知误报、ros2_control 差异，均有回退开关

  6. M5：一键全链 + 录像 + 验收单，进入 CI
