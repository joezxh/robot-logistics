设计第 2 节：ROS2 接口契约

Gateway 仅下发任务级 Action；事件触发拉取 + 周期心跳保持 Web 状态同步；Gazebo 与未来硬件共享 arm_hal 抽象。

A. ROS2 包与节点
robot_msgs # Action/Service/Topic/Message robot_bringup # launch + 参数选择 robot_moveit_config # SRDF/Kinematics/Plugins robot_gateway # Action 客户端，状态聚合，心跳 robot_decision # 状态机，抓取候选，恢复 robot_perception # 相机 + 检测 + 位姿 + PlanningScene robot_arm_hal # 硬件抽象（Gazebo/真实两套驱动 + 同一接口）
B. 关键 Action / Service
robot_msgs/action/PickPlace
goal: target_object_id · place_zone_id · params
feedback: stage · progress · last_error
result: success · stats · failure_reason
MoveGroup action：交给 MoveIt 2
ExecuteTrajectory action：真实下发
Perception/detect_objects srv：按需同步触发
PlanningScene/update srv：添加/移除障碍物
C. 关键 Topic
cam /<ns>/camera/image_raw (BE)
cam /<ns>/camera/points (BE)
pcp /<ns>/perception/detections (RV)
pcp /<ns>/perception/poses (BE+KEEP_LAST)
dec /<ns>/decision/feedback (BE)
mv /<ns>/planning_scene_motion (BE)
gw /<ns>/robot/state (RV+KEEP_LAST)
gw /<ns>/robot/diagnostics (BE)
safe /<ns>/estop (RV+TL)
safe /<ns>/arm_state_mode (RV+KEEP_LAST)
D. TF 树与命名约定
world → map → robot_base
→ arm_base → shoulder → link1..link6 → gripper_frame
·· gripper_tip（TCP）
·· camera_optical_frame（外参固定）
·· detected_object_N（检测结果，TTL 5s）

ns 命名：<env>_<device_id>
例：sim_robot01、real_robot01
E. QoS 与安全信道
实时类（BE）
camera/*、perception/poses、decision/feedback、diagnostics
深度 LATEST=1；订阅通过事件触发
状态类（RV+TL）
/robot/state、/arm_state_mode、estop、goal/cancel
用于 Web 重连与延迟加入
关键指令（RV）
Action goal/feedback/result、Service 调用
动作取消走专门 Action 接口

安全信道：急停/模式只接受来自网关或本机 HMI 的写权限；任一节点心跳超时 3 倍周期即进入 fault 模式，机器人停机并尝试保留最近安全位置。

F. arm_hal 抽象接口
robot_msgs/action/ExecuteJointTrajectory // 带宽采样轨迹
robot_msgs/srv/GetRobotState // 关节位置/速度、夹具、外部状态
robot_msgs/srv/SetToolPower // 夹具吸/夹/释放
ros2_control hardware_interface // 兼容 JointTrajectoryController

robot_arm_hal_gazebo // Gazebo Fortress 实现
robot_arm_hal_real // 真实机械臂实现（后期）
